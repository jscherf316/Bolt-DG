# Puzzle-room ghosts. Two attackable NPCs sharing ONE mesh (n=1428) that differ
# only in baked vertex brightness -- the DARK one is the vulnerable GOOD_GHOST,
# the light ones are BAD_GHOSTs, and the game rotates which ghost is vulnerable
# on a timer.
#
# These are NOT resources. They never enter the unknown queue, never bind a
# sighting and never reach the parity evidence -- main.lua detects them ahead of
# the resource path and returns. The only consumer is the in-world highlight.
#
# Same format as guardian_doors.txt: NAME|tier|n|ix,x,y,z,r,g,b|... (5 samples).
# Positions are recorded for reference only; matching is by vertexcount plus a
# scale-invariant colour signature, because these animate. The two luminances
# below set the single-ghost fallback threshold (their midpoint); with two or
# more ghosts on screen the darkest is picked instead, which is robust to the
# room's lighting in a way an absolute threshold is not.
